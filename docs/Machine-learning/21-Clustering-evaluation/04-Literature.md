# Дополнительная литература

Дополнительно с методами оценки качества кластеризации вы можете ознакомиться в специализированных статьях [[1]](https://onlinelibrary.wiley.com/doi/full/10.1002/sam.10080) и [[2]](https://www.researchgate.net/profile/Milos-Radovanovic-5/publication/301736217_Clustering_Evaluation_in_High-Dimensional_Data/links/602a341b4585158939a6c5da/Clustering-Evaluation-in-High-Dimensional-Data.pdf). Также кратко список мер оценки качества кластеризации вместе с их вычислительной сложностью представлен в [[3]](https://neerc.ifmo.ru/wiki/index.php?title=Оценка_качества_в_задаче_кластеризации).

## Литература

1. [Vendramin L., Campello R. J. G. B., Hruschka E. R. Relative clustering validity criteria: A comparative overview //Statistical analysis and data mining: the ASA data science journal. – 2010. – Т. 3. – №. 4. – С. 209-235.](https://onlinelibrary.wiley.com/doi/full/10.1002/sam.10080)
2. [Tomašev N., Radovanović M. Clustering evaluation in high-dimensional data //Unsupervised learning algorithms. – Cham : Springer International Publishing, 2016. – С. 71-107.](https://www.researchgate.net/profile/Milos-Radovanovic-5/publication/301736217_Clustering_Evaluation_in_High-Dimensional_Data/links/602a341b4585158939a6c5da/Clustering-Evaluation-in-High-Dimensional-Data.pdf)
3. [Викиконспекты ИТМО: Оценка качества в задаче кластеризации.](https://neerc.ifmo.ru/wiki/index.php?title=Оценка_качества_в_задаче_кластеризации)
