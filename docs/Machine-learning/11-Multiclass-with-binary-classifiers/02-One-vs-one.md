# Метод один-против-одного

**Метод один-против-одного** (one-vs-one) представляет собой альтернативный метод многоклассовой классификации с помощью набора бинарных классификаторов.

Для начала рассмотрим похожую задачу, когда у нас есть $C$ футбольных команд, и нам нужно определить среди них самую сильную. Мы не можем заставить играть одновременно больше двух команд, поэтому проведём матчи между каждой парой команд. Всего таких пар будет $C(C-1)/2$. Самой сильной командой тогда можно назначить ту команду, которая победила в максимальном числе матчей. Если лучшие команды побеждали одинаковое число раз, то назначим самой лучшей среди них ту, которая при этом ещё забила в соревнованиях наибольшее число голов.

Аналогично работает и метод один-против-одного. Настраивается $C(C-1)/2$ бинарных классификаторов, определяющих, какой класс лучше подходит объекту, *если выбирать только между $i$-м и $j$-м классом*:

$$
\hat{y}=\text{sign}(g_{ij}(\mathbf{x}))
$$

Настройка каждого такого классификатора производится по подвыборке объектов, принадлежащих либо $i$-му, либо $j$-му классу.

Далее для нового объекта тестовой выборки назначается тот класс, *который побеждает в максимальном числе попарных сравнений этого класса с другими классами*. Если несколько классов побеждают другие одинаковое число раз, то среди них выбирается тот, который побеждает остальных *с максимальной суммой относительных дискриминантных функций соответствующих классификаторов.*

:::tip Сложность оценивания

Метод один-против-одного требует оценки $C(C-1)/2$ бинарных классификаторов, в то время как метод один-против-всех - только $C$ классификаторов. Однако в первом методе оценка производится каждый раз <u>по подвыборке объектов</u> двух соответствующих классов, в том время как во втором методе - каждый раз по всем объектам выборки. 

Поэтому, несмотря на то, что классификаторов нужно оценить больше, совокупное время оценивания может получиться меньше, если сложность настройки модели нелинейно возрастает с объемом обучающей выборки, как, например, в [ядерно обобщённом методе опорных векторов](../Linear-classification/SVM).

:::

<details>
  <summary>Каким методом, одним-против-одного или одним-против-всех, вычислительно сложнее строить прогноз? </summary>

<p>
Если считать, что сложность прогнозирования каждым бинарным классификатором примерно одинаковая, то метод один-против-всех строит прогнозы быстрее, поскольку для него нужно пропустить объект через $C$ классификаторов, в то время как для метода один-против-одного - уже через $C(C-1)/2$ классификаторов.
</p>

</details>

Реализацию метода на python см. в документации sklearn [[1]](https://scikit-learn.org/stable/modules/multiclass.html#onevsoneclassifier).
