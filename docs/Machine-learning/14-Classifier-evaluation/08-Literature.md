# Дополнительная литература

Оценка качества классификации подробно описана в [[1]](https://github.com/Dyakonov/MLDM_BOOK/blob/main/book_074_rocauc_202410.pdf), также можете прочитать соответствующий раздел в учебнике ШАД [[2]](https://education.yandex.ru/handbook/ml/article/metriki-klassifikacii-i-regressii).

Детальнее о ROC-кривой, истории её появления и альтернативных мерах качества можно прочитать в [[3]](https://en.wikipedia.org/wiki/Receiver_operating_characteristic). С реализацией всевозможных мер качества на python можно ознакомиться в [[4]](https://scikit-learn.org/stable/modules/model_evaluation.html#classification-metrics).

## Литература

1. [Дьяконов А.Г. Машинное обучение и анализ данных: кривые в машинном обучении.](https://github.com/Dyakonov/MLDM_BOOK/blob/main/book_074_rocauc_202410.pdf)
2. [Учебник ШАД: метрики классификации и регрессии.](https://education.yandex.ru/handbook/ml/article/metriki-klassifikacii-i-regressii)
3. [Wikipedia: receiver operating characteristic.](https://en.wikipedia.org/wiki/Receiver_operating_characteristic)
4. [Документация sklearn: classification metrics.](https://scikit-learn.org/stable/modules/model_evaluation.html#classification-metrics)
