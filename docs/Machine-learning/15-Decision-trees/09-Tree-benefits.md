# Анализ решающих деревьев

Решающие деревья являются одними из самых используемых алгоритмов классического машинного обучения. Проанализируем их достоинства и недостатки.

## Достоинства метода

- Это <u>нелинейная модель с гибкой настройкой сложности</u> по максимальной глубине и минимальному числу объектов в листе. Настраивая деревья достаточной глубины, можно сколь угодно точно подогнать модель под данные (если одинаковым объектам не соответствуют разные отклики).

- Модель <u>самостоятельно отбирает важные признаки</u>. Неинформативные признаки не будут использованы в прогнозах.

- Модель универсально <u>работает с признаками разной природы</u>, поскольку правила [признак$\le$порог] одинаково применимы и к вещественным, и к бинарным, и к порядковым (упорядоченным категориальным) признакам. Категориальные же признаки всегда можно предварительно преобразовать в бинарные или вещественные одним из [стандартных способов](../Data-preprocessing/Categorical-preprocessing). Это важное качество, поскольку в большинстве задач мы будем иметь дело с признаками разных типов!

- По дереву можно рассчитать [важность каждого признака](Feature-importances) для построения прогнозов, что может использоваться как для анализа самого решающего дерева, так и для отбора признаков для моделей других типов (например, нейросетей).

- Деревья <u>инвариантны к масштабу и монотонным преобразованиям признаков</u>, поскольку к ним инвариантны заложенные в них правила [признак$\le$порог] после перенастройки моделей. 

- <u>Прогнозы строятся быстро</u>, поскольку прогнозирующая функция требует только сравнения определённых признаков с порогом.

- Решающие деревья небольшой глубины можно <u>визуализировать и проинтерпретировать</u> даже не специалистам.

## Недостатки метода

- У решающих деревьев <u>нет динамической подстройки под потоковые данные</u>. При поступлении новых данных дерево необходимо перестраивать с самого начала до самого конца. При этом решающие правила могут поменяться, начиная с самого верха дерева! То есть это <u>неустойчивый алгоритм</u> даже к небольшим изменениям обучающей выборки.

- У деревьев сравнительно невысокая точность. Это связано со следующими свойствами:
  
  - Дерево настраивается жадным способом сверху вниз, последовательно выбирая оптимальные правила разбиения, заглядывая <u>лишь на один шаг вперёд</u>. В результате дерево, как целое, будет оказываться неоптимальным - можно достичь более высокой точности при меньшем числе разбиений. 
  
  - Правила [признак$\le$порог] разделяют признаковое пространство гиперплоскостями, перпендикулярными осям координат, в результате чего получается кусочно-постоянная функция прогноза. Такая функция будет <u>неточно прогнозировать</u> плавные изменения отклика, а также изменения, происходящие не вдоль отдельного признака, а под углом к осям координат признакового пространства.

:::tip Увеличение точности деревьев

Точность решающих деревьев можно существенно повысить, если использовать для прогнозов не одно дерево, а набор из нескольких деревьев (ансамбль). О построении ансамблей моделей будет рассказано [в следующей главе](../Model-ensembles/Model-ensembles). Отдельный раздел учебника посвящён построению ансамблей с помощью [алгоритма бустинга](../Boosting).

Ансамбли над решающими деревьями - это <u>самый часто используемый метод классического машинного обучения</u>!

:::
