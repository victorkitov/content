# Дополнительная литература

Алгоритм бустинга подробно изложен в [[1]](https://hastie.su.domains/ElemStatLearn/). Также ознакомиться с методом можно в [[2]](https://education.yandex.ru/handbook/ml/article/gradientnyj-busting). 

В [[3]](https://scikit-learn.org/stable/modules/ensemble.html) описана реализация и примеры запуска классического бустинга в библиотеке sklearn. Примеры запуска и основные параметры продвинутых реализаций бустинга XGBoost и CatBoost со ссылками для более полного погружения есть в [[4]](https://neerc.ifmo.ru/wiki/index.php?title=XGBoost) и [[5]](https://neerc.ifmo.ru/wiki/index.php?title=CatBoost).

## Литература

1. [Hastie T., Tibshirani R., Friedman J. The Elements of Statistical Learning: Data Mining, Inference, and Prediction. – Springer Science & Business Media, 2009.](https://hastie.su.domains/ElemStatLearn/)
2. [Учебник ШАД: градиентный бустинг.](https://education.yandex.ru/handbook/ml/article/gradientnyj-busting)
3. [Документация sklearn: ensembles, gradient boosting, random forests, bagging, voting, stacking.](https://scikit-learn.org/stable/modules/ensemble.html)
4. [Викиконспекты ИТМО: XGBoost.](https://neerc.ifmo.ru/wiki/index.php?title=XGBoost)
5. [Викиконспекты ИТМО: CatBoost.](https://neerc.ifmo.ru/wiki/index.php?title=CatBoost)
