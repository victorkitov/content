Нахождение главных компонент

Дисперсия вдоль направления​

Пусть данные {xn}n=1N\{\boldsymbol{x}_n\}_{n=1}^N{xn​}n=1N​ имеют вектор среднего μ\boldsymbol{\mu}μ и ковариационную матрицу Σ\SigmaΣ, которые по обучающей выборке вычисляются как выборочные оценки:

μ=1N∑n=1Nxn\boldsymbol{\mu} = \frac{1}{N} \sum_{n=1}^N \boldsymbol{x}_nμ=N1​n=1∑N​xn​ Σ=1N∑n=1N(xn−μ)(xn−μ)T\Sigma = \frac{1}{N} \sum_{n=1}^N (\boldsymbol{x}_n - \boldsymbol{\mu})(\boldsymbol{x}_n - \boldsymbol{\mu})^TΣ=N1​n=1∑N​(xn​−μ)(xn​−μ)T

Утверждение: дисперсия проекций

Дисперсия D\mathbb{D}D проекций данных на вектор v\boldsymbol{v}v единичной длины выражается как vTΣv\boldsymbol{v}^T \Sigma \boldsymbol{v}vTΣv.

Доказательство:

Рассмотрим дисперсию скалярного произведения z=vTxz = \boldsymbol{v}^T \boldsymbol{x}z=vTx:

D(z)=E[(z−E[z])2]=E[(vTx−vTμ)2]=E[(vT(x−μ))2]\begin{aligned} \mathbb{D}(z) &= \mathbb{E}[(z - \mathbb{E}[z])^2] \\ &=\mathbb{E}[(\boldsymbol{v}^T \boldsymbol{x} - \boldsymbol{v}^T \boldsymbol{\mu})^2] \\ &= \mathbb{E}[(\boldsymbol{v}^T (\boldsymbol{x} - \boldsymbol{\mu}))^2] \end{aligned}D(z)​=E[(z−E[z])2]=E[(vTx−vTμ)2]=E[(vT(x−μ))2]​

Используя линейность математического ожидания, правила транспонирования (AB)T=BTAT(AB)^T = B^T A^T(AB)T=BTAT и свойство, что при транспонировании скаляра vT(x−μ)\boldsymbol{v}^T (\boldsymbol{x} - \boldsymbol{\mu})vT(x−μ) он не меняется, получим:

D(z)=E[(vT(x−μ))2]=E[(vT(x−μ))(vT(x−μ))T]=E[vT(x−μ)(x−μ)Tv]=vTE[(x−μ)(x−μ)T]v\begin{aligned} \mathbb{D}(z) &= \mathbb{E}\left[ \left( \boldsymbol{v}^T (\boldsymbol{x} - \boldsymbol{\mu}) \right)^2 \right] \\ &= \mathbb{E}\left[ \left( \boldsymbol{v}^T (\boldsymbol{x} - \boldsymbol{\mu}) \right) \left( \boldsymbol{v}^T (\boldsymbol{x} - \boldsymbol{\mu}) \right)^T \right] \\ &= \mathbb{E}\left[ \boldsymbol{v}^T (\boldsymbol{x} - \boldsymbol{\mu}) (\boldsymbol{x} - \boldsymbol{\mu})^T \boldsymbol{v} \right] \\ &= \boldsymbol{v}^T \mathbb{E}\left[ (\boldsymbol{x} - \boldsymbol{\mu}) (\boldsymbol{x} - \boldsymbol{\mu})^T \right] \boldsymbol{v} \end{aligned}D(z)​=E[(vT(x−μ))2]=E[(vT(x−μ))(vT(x−μ))T]=E[vT(x−μ)(x−μ)Tv]=vTE[(x−μ)(x−μ)T]v​

Подставляя определение матрицы Σ\SigmaΣ, получим требуемое утверждение:

D(z)=vTΣv\mathbb{D}(z) = \boldsymbol{v}^T \Sigma \boldsymbol{v}D(z)=vTΣv

□\square□

Далее мы будем определять самое информативное направление v\boldsymbol{v}v, вдоль которого дисперсия проекций объектов окажется максимальной.

Первая главная компонента​

Первая главная компонента

Первая главная компонента (first principal component) — это направление в пространстве исходных признаков, задаваемое вектором v1\boldsymbol{v}_1v1​ единичной нормы (∥v1∥=1\|\boldsymbol{v}_1\|=1∥v1​∥=1), такое, что проекция центрированных данных на это направление обладает максимально возможной дисперсией.

Утверждение: первая главная компонента

Вектор v1\boldsymbol{v}_1v1​, максимизирующий дисперсию проекций {xn}n=1N\{\boldsymbol{x}_n\}_{n=1}^N{xn​}n=1N​ на него, является собственным вектором матрицы Σ\SigmaΣ, отвечающим её максимальному собственному значению λ1\lambda_1λ1​.

Доказательство:

Для поиска первой главной компоненты v1\boldsymbol{v}_1v1​ необходимо решить следующую оптимизационную задачу:

{vTΣv→max⁡vvTv=1\begin{cases} \boldsymbol{v}^T \Sigma \boldsymbol{v} \to \max_{\boldsymbol{v}} \\ \boldsymbol{v}^T \boldsymbol{v} = 1 \end{cases}{vTΣv→maxv​vTv=1​

Для решения этой задачи используется метод множителей Лагранжа [1]. Мы переходим от поиска экстремума функции при ограничении к поиску стационарных точек лагранжиана:

L(v,λ)=vTΣv−λ(vTv−1)L(\boldsymbol{v}, \lambda) = \boldsymbol{v}^T \Sigma \boldsymbol{v} - \lambda (\boldsymbol{v}^T \boldsymbol{v} - 1)L(v,λ)=vTΣv−λ(vTv−1)

где λ\lambdaλ — множитель Лагранжа. Необходимым условием экстремума является равенство нулю частной производной по v\boldsymbol{v}v:

∂L∂v=∂∂v(vTΣv)−∂∂v(λvTv)=0\frac{\partial L}{\partial \boldsymbol{v}} = \frac{\partial}{\partial \boldsymbol{v}} (\boldsymbol{v}^T \Sigma \boldsymbol{v}) - \frac{\partial}{\partial \boldsymbol{v}} (\lambda \boldsymbol{v}^T \boldsymbol{v}) = 0∂v∂L​=∂v∂​(vTΣv)−∂v∂​(λvTv)=0

Используя правила матричного дифференцирования (∂aTAa∂a=2Aa\frac{\partial \boldsymbol{a}^T A \boldsymbol{a}}{\partial \boldsymbol{a}} = 2A\boldsymbol{a}∂a∂aTAa​=2Aa для симметричной матрицы AAA [2]), получаем:

2Σv−2λv=0  ⟹  Σv=λv2 \Sigma \boldsymbol{v} - 2 \lambda \boldsymbol{v} = 0 \implies \Sigma \boldsymbol{v} = \lambda \boldsymbol{v}2Σv−2λv=0⟹Σv=λv

Следовательно, v\boldsymbol{v}v является одним из собственных векторов матрицы Σ\SigmaΣ.

Дисперсия при этом равна

D(z)=vTΣv=vTλv=λvTv=λ\mathbb{D}(z) = \boldsymbol{v}^T \Sigma \boldsymbol{v} = \boldsymbol{v}^T \lambda \boldsymbol{v} = \lambda \boldsymbol{v}^T \boldsymbol{v} = \lambdaD(z)=vTΣv=vTλv=λvTv=λ

Поскольку нас интересует максимизация дисперсии, v\boldsymbol{v}v следует выбрать собственным вектором v1\boldsymbol{v}_1v1​ матрицы Σ\SigmaΣ, отвечающим максимальному собственному значению λ1\lambda_1λ1​.

□\square□

Спектральная теорема

Так как Σ∈RD×D\Sigma\in\mathbb{R}^{D\times D}Σ∈RD×D — симметричная вещественная матрица, то согласно спектральной теореме [3], её собственные значения вещественны, а собственные вектора образуют ортонормированный базис. То есть она обладает набором из DDD собственных векторов, которые ортогональны друг другу.

Обозначим за v1,v2,...vD \boldsymbol{v}_1, \boldsymbol{v}_2,... \boldsymbol{v}_Dv1​,v2​,...vD​ собственные вектора Σ\SigmaΣ, отвечающие собственным значениям λ1≥λ2≥λD≥0\lambda_1 \ge \lambda_2 \ge \lambda_D \ge 0λ1​≥λ2​≥λD​≥0. Все собственные значения неотрицательны, поскольку по свойству дисперсии, доказанному выше,

viTΣvi=λiviTvi=λi=D(viTx)≥0\boldsymbol{v_i}^T \Sigma \boldsymbol{v_i}=\lambda_i \boldsymbol{v_i}^T \boldsymbol{v_i}=\lambda_i=\mathbb{D}(\boldsymbol{v}_i^T \boldsymbol{x})\ge 0vi​TΣvi​=λi​vi​Tvi​=λi​=D(viT​x)≥0

Последующие главные компоненты​

подсказка
iii-я главная компонента

iii-я главная компонента (i=1,2,...Di=1,2,...Di=1,2,...D — это направление, задаваемое вектором vM+1\boldsymbol{v}_{M+1}vM+1​ единичной нормы, которое

  1. обеспечивает максимум дисперсии проекций данных на неё;

  2. ортогональна всем ранее найденным компонентам v1,…,vi−1\boldsymbol{v}_1, \dots, \boldsymbol{v}_{i-1}v1​,…,vi−1​.

Утверждение: (K+1) главная компонента

(K+1)(K+1)(K+1)-я главная компонента является собственным вектором Σ\SigmaΣ, отвечающим (K+1)(K+1)(K+1)-му по величине собственному числу.

Доказательство:

Докажем утверждение по индукции.

Как было показано выше, при K=0K=0K=0 утверждение выполнено.

Допустим, уже найдены KKK главных компонент v1,…,vK\boldsymbol{v}_1, \dots, \boldsymbol{v}_Kv1​,…,vK​, отвечающие собственным векторам матрицы Σ\SigmaΣ с собственными значениями λ1≥λ2≥λK\lambda_1 \ge \lambda_2 \ge \lambda_Kλ1​≥λ2​≥λK​. По спектральной теореме они будут ортогональны друг другу. Докажем верность утверждения для (K+1)(K+1)(K+1)-й компоненты.

Математически оптимизационная задача для (K+1)(K+1)(K+1)-й главной компоненты записывается следующим образом:

{vTΣv→max⁡vvTv=1vTvj=0,j=1,…,K\begin{cases} \boldsymbol{v}^T \Sigma \boldsymbol{v} \to \max_{\boldsymbol{v}} \\ \boldsymbol{v}^T \boldsymbol{v} = 1 \\ \boldsymbol{v}^T \boldsymbol{v}_j = 0, \quad j = 1, \dots, K \end{cases}⎩⎨⎧​vTΣv→maxv​vTv=1vTvj​=0,j=1,…,K​

Решать задачу будем методом множителей Лагранжа [1]. Соответствующий лагранжиан равен

L(v,λ,η1,…,ηK)=vTΣv−λ(vTv−1)−∑j=1KηjvTvjL(\boldsymbol{v}, \lambda, \eta_1, \dots, \eta_K) = \boldsymbol{v}^T \Sigma \boldsymbol{v} - \lambda (\boldsymbol{v}^T \boldsymbol{v} - 1) - \sum_{j=1}^K \eta_j \boldsymbol{v}^T \boldsymbol{v}_jL(v,λ,η1​,…,ηK​)=vTΣv−λ(vTv−1)−j=1∑K​ηj​vTvj​

с двойственными переменными λ,η1,…,ηK\lambda, \eta_1, \dots, \eta_Kλ,η1​,…,ηK​, отвечающими соответствующим ограничениям.

Запишем условие стационарности лагранжиана по v\boldsymbol{v}v:

∂L∂v=2Σv−2λv−∑j=1Kηjvj=0(1)\tag{1} \frac{\partial L}{\partial \boldsymbol{v}} = 2 \Sigma \boldsymbol{v} - 2 \lambda \boldsymbol{v} - \sum_{j=1}^K \eta_j \boldsymbol{v}_j = 0∂v∂L​=2Σv−2λv−j=1∑K​ηj​vj​=0(1)

Умножим полученное уравнение слева на viT\boldsymbol{v}_i^TviT​, i≤Ki \le Ki≤K (одну из ранее найденных главных компонент):

2viTΣv−2λviTv−∑j=1Kηj(viTvj)=02 \boldsymbol{v}_i^T \Sigma \boldsymbol{v} - 2 \lambda \boldsymbol{v}_i^T \boldsymbol{v} - \sum_{j=1}^K \eta_j (\boldsymbol{v}_i^T \boldsymbol{v}_j) = 02viT​Σv−2λviT​v−j=1∑K​ηj​(viT​vj​)=0

Из предположения индукции viTvj=I{i=j}\boldsymbol{v}_i^T \boldsymbol{v}_j = \mathbb{I}\{i=j\}viT​vj​=I{i=j}, поэтому получим

2viTΣv−2λviTv−ηi=0(2)\tag{2} 2 \boldsymbol{v}_i^T \Sigma \boldsymbol{v} - 2 \lambda \boldsymbol{v}_i^T \boldsymbol{v} - \eta_i = 02viT​Σv−2λviT​v−ηi​=0(2)

Заметим, что viTv=0\boldsymbol{v}_i^T \boldsymbol{v}=0viT​v=0 по условию решаемой оптимизационной задачи. Также

viTΣv=(viTΣv)T=vTΣvi=λivTvi=0\boldsymbol{v}_i^T \Sigma \boldsymbol{v} = (\boldsymbol{v}_i^T \Sigma \boldsymbol{v})^T= \boldsymbol{v}^T \Sigma \boldsymbol{v}_i = \lambda_i \boldsymbol{v}^T \boldsymbol{v}_i = 0viT​Σv=(viT​Σv)T=vTΣvi​=λi​vTvi​=0

Следовательно, (2) сводится к условию ηi=0\eta_i = 0ηi​=0, причём это справедливо для любого i=1,2,...Ki=1,2,...Ki=1,2,...K. Значит (1) сводится к уравнению на собственные числа Σv=λv\Sigma \boldsymbol{v} = \lambda \boldsymbol{v}Σv=λv.

Чтобы максимизировать дисперсию D(vTx)=λ\mathbb{D}(\boldsymbol{v}^T \boldsymbol{x}) = \lambdaD(vTx)=λ, соблюдая при этом ортогональность ранее найденным главным компонентам v1,…,vK\boldsymbol{v}_1, \dots, \boldsymbol{v}_Kv1​,…,vK​, мы должны выбрать собственный вектор vK+1\boldsymbol{v}_{K+1}vK+1​ матрицы Σ\SigmaΣ, отвечающий (K+1)(K+1)(K+1)-му по величине собственному значению λK+1\lambda_{K+1}λK+1​. Ортогональность при этом обеспечивается тем, что собственные векторы образуют ортонормированный базис согласно спектральной теореме.

□\square□

Значение каждой главной компоненты

Последовательно применяя полученный результат для K=1,2,...D−1K=1,2,...D-1K=1,2,...D−1, получим, что kkk-я главная компонента равна собственному вектору vk\boldsymbol{v}_kvk​ матрицы Σ\SigmaΣ, отвечающему kkk-му собственному вектору.

Утверждение: дисперсия проекций на компоненту

Дисперсия проекции данных на kkk-ю главную компоненту равна соответствующему собственному числу λk\lambda_kλk​.

Доказательство:

Для kkk-й компоненты vk\boldsymbol{v}_kvk​ выполняется Σvk=λkvk\Sigma \boldsymbol{v}_k = \lambda_k \boldsymbol{v}_kΣvk​=λk​vk​. Подставляя это в формулу для дисперсии вдоль направления, получим:

D(zk)=vkTΣvk=vkT(λkvk)=λk∥vk∥2=λk\begin{aligned} \mathbb{D}(z_k) &= \boldsymbol{v}_k^T \Sigma \boldsymbol{v}_k \\ &= \boldsymbol{v}_k^T (\lambda_k \boldsymbol{v}_k) = \lambda_k \|\boldsymbol{v}_k\|^2 = \lambda_k \end{aligned}D(zk​)​=vkT​Σvk​=vkT​(λk​vk​)=λk​∥vk​∥2=λk​​

□\square□
