Глобальная оптимальность главных компонент

Рассмотрим конечную выборку наблюдений x1,x2,...xN\boldsymbol{x}_1,\boldsymbol{x}_2,...\boldsymbol{x}_Nx1​,x2​,...xN​ и произвольную ортонормированную систему векторов {ui}i=1K\{\boldsymbol{u}_i\}_{i=1}^K{ui​}i=1K​.

Проекцию объекта x\boldsymbol{x}x на iii-й вектор будем обозначать как ziz^izi:

zi=uiTxz^i = \boldsymbol{u}_i^T \boldsymbol{x}zi=uiT​x

Проекцию nnn-го объекта xn\boldsymbol{x}_nxn​ на iii-й вектор будем обозначать как zniz^i_nzni​:

zni=uiTxnz^i_n = \boldsymbol{u}_i^T \boldsymbol{x}_nzni​=uiT​xn​

Будем рассматривать только предварительно центрированные признаки (из каждого признака вычитаем его мат. ожидание). Для центрированных признаков проекции также будут обладать нулевым мат. ожиданием (показывалось ранее).

Поскольку данные описываются конечной выборкой объектов x1,x2,...xN\boldsymbol{x}_1,\boldsymbol{x}_2,...\boldsymbol{x}_Nx1​,x2​,...xN​, то операции математического ожидания и дисперсии следует понимать в конечном пространстве исходов этой выборки, т.е. как выборочное среднее и выборочную дисперсию.

Поскольку данные и проекции центрированы в нуле, то для i=1,2,...Ki=1,2,...Ki=1,2,...K:

D{zi}=E{(zi)2}−(E{(zi)2})2=E{(zi)2}\mathbb{D}\{z^i\} = \mathbb{E}\{(z^i)^2\} - \left(\mathbb{E}\{(z^i)^2\}\right)^2=\mathbb{E}\{(z^i)^2\}D{zi}=E{(zi)2}−(E{(zi)2})2=E{(zi)2}

Пусть подпространство U=L(u1,u2,...uK)U=\mathcal{L}(\boldsymbol{u}_1,\boldsymbol{u}_2,...\boldsymbol{u}_K)U=L(u1​,u2​,...uK​) задано ортонормированным базисом {ui}i=1K\{\boldsymbol{u}_i\}_{i=1}^K{ui​}i=1K​. Для любого центрированного вектора объекта x\boldsymbol{x}x его можно представить в виде суммы двух составляющих:

x=x^+h,\boldsymbol{x} = \hat{\boldsymbol{x}} + \boldsymbol{h},x=x^+h,

где

  • x^=∑i=1K(uiTx)ui=∑i=1Kziui\hat{\boldsymbol{x}} = \sum_{i=1}^K (\boldsymbol{u}_i^T \boldsymbol{x}) \boldsymbol{u}_i = \sum_{i=1}^K z^i \boldsymbol{u}_ix^=∑i=1K​(uiT​x)ui​=∑i=1K​ziui​ — векторная проекция x\boldsymbol{x}x на подпространство UUU (по смыслу - аппроксимация x\boldsymbol{x}x в KKK-мерном подпространстве UUU)

  • h\boldsymbol{h}h — ортогональное дополнение к проекции (ошибка аппроксимации).

Введём понятие суммарной дисперсии проекций.

Dtotal=D{z1}+D{z2}+⋯+D{zK}\mathbb{D}_{total} = \mathbb{D}\{z^1\} + \mathbb{D}\{z^2\} + \dots + \mathbb{D}\{z^K\}Dtotal​=D{z1}+D{z2}+⋯+D{zK}

Утверждение 1:

Cуммарная дисперсия будет совпадать со средним квадратом длин векторов-апроксимаций.

Доказательство:

Dtotal=D{z1}+D{z2}+⋯+D{zK}=E{(z1)2}+E{(z2)2}+⋯+E{(zK)2}=1N∑n=1N(zn1)2+1N∑n=1N(zn2)2+…1N∑n=1N(znK)2=1N∑n=1N((zn1)2+(zn2)2+…(znK)2)=1N∑n=1N∥zn∥2=1N∑n=1N∥x^n∥2=E{∥x^∥2}\begin{align*} \mathbb{D}_{total} &= \mathbb{D}\{z^1\} + \mathbb{D}\{z^2\} + \dots + \mathbb{D}\{z^K\} \\ &= \mathbb{E}\{(z^1)^2\} + \mathbb{E}\{(z^2)^2\} + \dots + \mathbb{E}\{(z^K)^2\} \\ &=\frac{1}{N}\sum_{n=1}^N (z^1_n)^2 + \frac{1}{N}\sum_{n=1}^N (z^2_n)^2 + \dots \frac{1}{N}\sum_{n=1}^N (z^K_n)^2 \\ &=\frac{1}{N}\sum_{n=1}^N \left( (z^1_n)^2 + (z^2_n)^2 + \dots (z^K_n)^2 \right) =\frac{1}{N}\sum_{n=1}^N \|\boldsymbol{z}_n\|^2 \\ &=\frac{1}{N}\sum_{n=1}^N \|\hat{\boldsymbol{x}}_n\|^2 = \mathbb{E}\{\|\hat{\boldsymbol{x}}\|^2\} \end{align*}Dtotal​​=D{z1}+D{z2}+⋯+D{zK}=E{(z1)2}+E{(z2)2}+⋯+E{(zK)2}=N1​n=1∑N​(zn1​)2+N1​n=1∑N​(zn2​)2+…N1​n=1∑N​(znK​)2=N1​n=1∑N​((zn1​)2+(zn2​)2+…(znK​)2)=N1​n=1∑N​∥zn​∥2=N1​n=1∑N​∥x^n​∥2=E{∥x^∥2}​

□\square□

В процессе доказательства мы воспользовались следующим свойством:

Утверждение 2:

∥x^∥2=∥z∥2\|\hat{\boldsymbol{x}}\|^2 = \|\boldsymbol{z}\|^2∥x^∥2=∥z∥2

Доказательство:

Распишем квадрат евклидовой нормы вектора x^\hat{\boldsymbol{x}}x^ через скалярное произведение вектора самого на себя:

∥x^∥2=x^Tx^=(∑i=1Kziui)T(∑j=1Kzjuj)\|\hat{\boldsymbol{x}}\|^2 = \hat{\boldsymbol{x}}^T \hat{\boldsymbol{x}} = \left( \sum_{i=1}^K z^i \boldsymbol{u}_i \right)^T \left( \sum_{j=1}^K z^j \boldsymbol{u}_j \right)∥x^∥2=x^Tx^=(i=1∑K​ziui​)T(j=1∑K​zjuj​)

Используя свойство дистрибутивности и вынося скалярные координаты за знак транспонирования, получим двойную сумму:

∥x^∥2=∑i=1K∑j=1Kzizj(uiTuj)\|\hat{\boldsymbol{x}}\|^2 = \sum_{i=1}^K \sum_{j=1}^K z^i z^j (\boldsymbol{u}_i^T \boldsymbol{u}_j)∥x^∥2=i=1∑K​j=1∑K​zizj(uiT​uj​)

Поскольку вектора {ui}\{\boldsymbol{u}_i\}{ui​} ортонормированные, uiTuj=I{i=j}\boldsymbol{u}_i^T \boldsymbol{u}_j = \mathbb{I}\{i=j\}uiT​uj​=I{i=j}, следовательно

∥x^∥2=∑i=1K(zi)2=∥z∥2\|\hat{\boldsymbol{x}}\|^2 = \sum_{i=1}^K (z^i)^2 = \|\boldsymbol{z}\|^2∥x^∥2=i=1∑K​(zi)2=∥z∥2

□\square□

Геометрический смысл утверждения 1.

Равенство в утверждении 1 означает, что суммарный разброс проекций совпадает со средним квадратом расстояний от спроецированных точек до начала координат в подпространстве UUU, являющимся линейной оболочкой {ui}i=1K\{\boldsymbol{u}_i\}_{i=1}^K{ui​}i=1K​.

Ранее мы выводили каждую главную компоненту, как направление, обеспечивающее максимизацию дисперсии проекций на неё при условии ортогональности ранее найденным главным компонентам. Таким образом, каждая следующая главная компонента вводилась из соображений локальной оптимальности.

Оказывается, что полученные первые KKK главных компонент также обладают свойством глобальной оптимальности: проекции на эти KKK направлений максимизируют суммарную дисперсию проекций.

Утверждение 3 (оптимальность подпространства):

Подпространство, натянутое на первые KKK главных компонент, обладает максимальной суммарной дисперсией среди всех возможных подпространств размерности KKK. Суммарная дисперсия при этом равна

Dtotal=∑i=1Kλi\mathbb{D}_{total} = \sum_{i=1}^K \lambda_iDtotal​=i=1∑K​λi​

Доказательство:

Пусть {ui}i=1K\{\boldsymbol{u}_i\}_{i=1}^K{ui​}i=1K​ — произвольный ортонормированный базис некоторого KKK-мерного подпространства UUU. Как мы показали ранее, дисперсия проекций на отдельный вектор ui\boldsymbol{u}_iui​ равна uiTΣui\boldsymbol{u}_i^T \Sigma \boldsymbol{u}_iuiT​Σui​, следовательно суммарная дисперсия проекций на это подпространство равна:

Dtotal(U)=∑i=1KuiTΣui\mathbb{D}_{total}(U) = \sum_{i=1}^K \boldsymbol{u}_i^T \Sigma \boldsymbol{u}_iDtotal​(U)=i=1∑K​uiT​Σui​

Воспользуемся спектральным разложением ковариационной матрицы Σ=∑j=1DλjvjvjT\Sigma = \sum_{j=1}^D \lambda_j \boldsymbol{v}_j \boldsymbol{v}_j^TΣ=∑j=1D​λj​vj​vjT​, где vj\boldsymbol{v}_jvj​ — её собственные векторы, а λ1≥λ2≥⋯≥λD\lambda_1 \ge \lambda_2 \ge \dots \ge \lambda_Dλ1​≥λ2​≥⋯≥λD​ — упорядоченные собственные числа. Подставим это разложение в формулу дисперсии:

Dtotal(U)=∑i=1KuiT(∑j=1DλjvjvjT)ui\mathbb{D}_{total}(U) = \sum_{i=1}^K \boldsymbol{u}_i^T \left( \sum_{j=1}^D \lambda_j \boldsymbol{v}_j \boldsymbol{v}_j^T \right) \boldsymbol{u}_iDtotal​(U)=i=1∑K​uiT​(j=1∑D​λj​vj​vjT​)ui​ =∑i=1K∑j=1Dλj(uiTvj)2=∑j=1Dλj(∑i=1K(uiTvj)2)=∑j=1Dλjcj,= \sum_{i=1}^K \sum_{j=1}^D \lambda_j (\boldsymbol{u}_i^T \boldsymbol{v}_j)^2 = \sum_{j=1}^D \lambda_j \left( \sum_{i=1}^K (\boldsymbol{u}_i^T \boldsymbol{v}_j)^2 \right) = \sum_{j=1}^D \lambda_j c_j,=i=1∑K​j=1∑D​λj​(uiT​vj​)2=j=1∑D​λj​(i=1∑K​(uiT​vj​)2)=j=1∑D​λj​cj​,

где мы ввели обозначение cj=∑i=1K(uiTvj)2c_j = \sum_{i=1}^K (\boldsymbol{u}_i^T \boldsymbol{v}_j)^2cj​=∑i=1K​(uiT​vj​)2.

Заметим, что cjc_jcj​ представляет собой квадрат длины проекции единичного вектора vj\boldsymbol{v}_jvj​ на подпространство UUU, следовательно, 0≤cj≤10 \le c_j \le 10≤cj​≤1. Кроме того, сумма всех cjc_jcj​ (по всем главным компонентам) равна:

∑j=1Dcj=∑j=1D∑i=1K(uiTvj)2=∑i=1K∑j=1D(uiTvj)2=∑i=1K∥ui∥2=K\sum_{j=1}^D c_j = \sum_{j=1}^D\sum_{i=1}^K (\boldsymbol{u}_i^T \boldsymbol{v}_j)^2 = \sum_{i=1}^K \sum_{j=1}^D (\boldsymbol{u}_i^T \boldsymbol{v}_j)^2 = \sum_{i=1}^K \|\boldsymbol{u}_i\|^2 = Kj=1∑D​cj​=j=1∑D​i=1∑K​(uiT​vj​)2=i=1∑K​j=1∑D​(uiT​vj​)2=i=1∑K​∥ui​∥2=K

Задача максимизации ∑j=1Dλjcj\sum_{j=1}^D \lambda_j c_j∑j=1D​λj​cj​ при условиях 0≤cj≤10 \le c_j \le 10≤cj​≤1 и ∑cj=K\sum c_j = K∑cj​=K, очевидно, решается выбором максимально возможных весов для самых больших коэффициентов λj\lambda_jλj​. Поскольку собственные числа упорядочены:

λ1≥λ2≥...λD≥0,\lambda_1\ge\lambda_2\ge...\lambda_D \ge 0,λ1​≥λ2​≥...λD​≥0,

необходимо положить c1=c2=⋯=cK=1c_1 = c_2 = \dots = c_K = 1c1​=c2​=⋯=cK​=1 и cK+1=⋯=cD=0c_{K+1} = \dots = c_D = 0cK+1​=⋯=cD​=0.

Это достигается, когда

u1=v1u2=v2⋯uK=vK\begin{align*} \boldsymbol{u}_1 &= \boldsymbol{v}_1\\ \boldsymbol{u}_2 &= \boldsymbol{v}_2\\ &\cdots \\ \boldsymbol{u}_K &= \boldsymbol{v}_K\\ \end{align*}u1​u2​uK​​=v1​=v2​⋯=vK​​

Таким образом, именно первые KKK главных компонент дают максимальную суммарную дисперсию проекций. При этом сама суммарная дисперсия будет равна

Dtotal(U)=∑j=1Dλjcj=∑i=1Kλi\mathbb{D}_{total}(U) = \sum_{j=1}^D \lambda_j c_j=\sum_{i=1}^K \lambda_iDtotal​(U)=j=1∑D​λj​cj​=i=1∑K​λi​

□\square□

Из утверждения 3 следует, что подпространство V=L(v1,v2,...vK)V=\mathcal{L}(\boldsymbol{v}_1,\boldsymbol{v}_2,...\boldsymbol{v}_K)V=L(v1​,v2​,...vK​) (линейная оболочка первых KKK главных компонент) является оптимальным в том смысле, что суммарный квадрат аппроксимаций исходных данных максимизируется при проецировании именно на такое KKK-мерное подпространство.

Интерпретация

Метод главных компонент находит наилучшее сжатие данных: среди всех способов линейно спроецировать объекты в KKK-мерное подпространство, именно PCA сохраняет наибольший объем «информации», выраженной через суммарный разброс спроецированных точек.

Оказывается, что подпространство VVV будет оптимальным и в том смысле, что именно оно минимизирует средний квадрат ошибок аппроксимации. Это следует из следующего утверждения:

Утверждение 4 (минимизация ошибок аппроксимации):

Среди всех линейных проекций в KKK-мерное подпространство именно PCA минимизирует математическое ожидание квадрата ошибки аппроксимации E[∥h∥2]\mathbb{E}[\|\boldsymbol{h}\|^2]E[∥h∥2].

Доказательство:

Распишем квадрат евклидовой нормы вектора x\boldsymbol{x}x через скалярное произведение вектора на самого себя:

∥x∥2=(x^+h)T(x^+h)\|\boldsymbol{x}\|^2 = (\hat{\boldsymbol{x}} + \boldsymbol{h})^T (\hat{\boldsymbol{x}} + \boldsymbol{h})∥x∥2=(x^+h)T(x^+h)

Раскроем скобки, используя свойство дистрибутивности:

∥x∥2=x^Tx^+x^Th+hTx^+hTh\|\boldsymbol{x}\|^2 = \hat{\boldsymbol{x}}^T \hat{\boldsymbol{x}} + \hat{\boldsymbol{x}}^T \boldsymbol{h} + \boldsymbol{h}^T \hat{\boldsymbol{x}} + \boldsymbol{h}^T \boldsymbol{h}∥x∥2=x^Tx^+x^Th+hTx^+hTh

По определению ортогональной проекции вектор ошибки h\boldsymbol{h}h перпендикулярен подпространству VVV, а значит, он перпендикулярен любому вектору из этого подпространства, включая саму проекцию x^\hat{\boldsymbol{x}}x^. Следовательно, скалярное произведение x^Th=0\hat{\boldsymbol{x}}^T \boldsymbol{h} = 0x^Th=0:

∥x∥2=∥x^∥2+0+0+∥h∥2=∥x^∥2+∥h∥2\|\boldsymbol{x}\|^2 = \|\hat{\boldsymbol{x}}\|^2 + 0 + 0 + \|\boldsymbol{h}\|^2 = \|\hat{\boldsymbol{x}}\|^2 + \|\boldsymbol{h}\|^2∥x∥2=∥x^∥2+0+0+∥h∥2=∥x^∥2+∥h∥2

Применим оператор математического ожидания к обеим частям равенства:

E[∥x∥2]=E[∥x^∥2]+E[∥h∥2]\mathbb{E}[\|\boldsymbol{x}\|^2] = \mathbb{E}[\|\hat{\boldsymbol{x}}\|^2] + \mathbb{E}[\|\boldsymbol{h}\|^2]E[∥x∥2]=E[∥x^∥2]+E[∥h∥2]

Выразим математическое ожидание квадрата ошибки аппроксимации:

E[∥h∥2]=E[∥x∥2]−E[∥x^∥2]\mathbb{E}[\|\boldsymbol{h}\|^2] = \mathbb{E}[\|\boldsymbol{x}\|^2] - \mathbb{E}[\|\hat{\boldsymbol{x}}\|^2]E[∥h∥2]=E[∥x∥2]−E[∥x^∥2]

Разберём слагаемые по отдельности:

  • Величина E[∥x∥2]\mathbb{E}[\|\boldsymbol{x}\|^2]E[∥x∥2] (полная дисперсия данных) не зависит от выбора подпространства и является постоянной для заданной выборки.

  • E[∥x^∥2]\mathbb{E}[\|\hat{\boldsymbol{x}}\|^2]E[∥x^∥2] максимизируется при проецировании именно на KKK первых главных компонент.

Отсюда следует что именно при проецировании на первых KKK главных компонент средний квадрат ошибок аппроксимации минимизируется.

□\square□
