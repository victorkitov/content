# Дополнительная литература

Мы рассмотрели линейную регрессию, её предположения, свойства, обобщения и способы внесения регуляризации в модель. Далее в отдельном разделе будут описаны методы [численной оптимизации](../Numerical-optimization) для настройки параметров линейной регрессии и других моделей.

Дополнительно по теме вы можете прочитать соответствующие главы учебника ШАД [[1]](https://education.yandex.ru/handbook/ml/article/linear-models) и учебника А. Г. Дьяконова [[2]](https://github.com/Dyakonov/MLDM_BOOK/blob/main/book_043_linreg_202305.pdf). Особенности реализации линейных моделей на python вы можете прочитать документации библиотеки sklearn [[3]](https://scikit-learn.org/stable/modules/linear_model.html).

## Литература

1. [Учебник ШАД: линейные модели.](https://education.yandex.ru/handbook/ml/article/linear-models)

2. [Дьяконов А.Г. Машинное обучение и анализ данных: линейная регрессия.](https://github.com/Dyakonov/MLDM_BOOK/blob/main/book_043_linreg_202305.pdf)

3. [Документация sklearn: linear models.](https://scikit-learn.org/stable/modules/linear_model.html)
