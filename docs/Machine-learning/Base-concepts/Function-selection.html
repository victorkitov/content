Настройка параметров модели

Можно вручную задать функцию соответствия y^=f(x)\hat{y}=f(\mathbf{x})y^​=f(x) (которую называют прогностической или прогнозной функцией), которая бы выдавала прогнозы отклика y^\hat{y}y^​ по известным признакам, однако зачастую это сложно сделать из-за многообразия объектов и сложных зависимостей между признаками и откликом. Поэтому в машинном обучении с учителем соответствие между признаками и откликом ищется в некотором классе функций fw(x)f_{\mathbf{w}}(\mathbf{x})fw​(x), параметризованном вектором параметров w\mathbf{w}w, которые подбираются по обучающей выборке, состоящей из NNN объектов:

(x1,y1),(x2,y2),...(xN,yN).(\mathbf{x}_1,y_1), (\mathbf{x}_2,y_2), ... (\mathbf{x}_N,y_N). (x1​,y1​),(x2​,y2​),...(xN​,yN​).

Параметры модели также будем называть весами модели (model weights).

Например, класс функций может быть множеством всех константных прогнозов:

fw(x)=w,w∈R,f_w(\mathbf{x})=w,\quad w\in\mathbb{R},fw​(x)=w,w∈R,

или состоять из всех линейных функций от признаков:

fw(x)=w0+w1x1+w2x2+...+wDxD,w=[w0,w1,...wD]∈RD+1f_{\mathbf{w}}(\mathbf{x})=w_0+w_1 x^1+w_2 x^2+...+w_D x^D, \quad \mathbf{w}=[w_0,w_1,...w_D]\in \mathbb{R}^{D+1}fw​(x)=w0​+w1​x1+w2​x2+...+wD​xD,w=[w0​,w1​,...wD​]∈RD+1

Существуют и более сложные семейства функций, о которых будет рассказано в следующих главах.

Чтобы из семейства функций выбрать наилучшую (что эквивалентно выбору определённого вектора параметров w^\hat{\mathbf{w}}w^) необходимо численно формализовать, какие прогнозы мы будем считать хорошими, а какие - плохими. Для этого задаётся функция потерь (loss function) L(y^,y)\mathcal{L}(\hat{y},y)L(y^​,y), зависящая от истинного значения отклика yyy и предсказанного y^\hat{y}y^​. Чем выше значение функции потерь, тем хуже считается прогноз.

Основные функции потерь в задаче регрессии​

Рассмотрим основные функции потерь в задаче регрессии:

названиеформула
квадрат ошибки (squared error, L2 loss)(y^−y)2(\hat{y}-y)^2(y^​−y)2
модуль ошибки (absolute error, L1 loss)∣y^−y∣\left\lvert\hat{y}-y\right\rvert∣y^​−y∣

Также широко используется гладкая комбинация обоих функций потерь, называемая функцией Хубера (smooth L1 loss):

{0.5⋅x2,если ∣x∣<β,β⋅(∣x∣−0.5⋅β),если ∣x∣≥β,\begin{cases} 0.5 \cdot x^2, & \text{если } |x| < \beta, \\ \beta \cdot (|x| - 0.5 \cdot \beta), & \text{если } |x| \geq \beta, \end{cases}{0.5⋅x2,β⋅(∣x∣−0.5⋅β),​если ∣x∣<β,если ∣x∣≥β,​

В последнем случае β>0\beta>0β>0 - гиперпараметр, задающий область квадратичной зависимости, которая продлевается линейно за пределами этой области, сохраняя непрерывность самой функции и непрерывность её производной.

Будучи гладкой, эта функция удобна для оптимизации, но в то же время так же устойчива к нетипичным наблюдениям, как и модуль ошибки.

Пример потерь для классификации​

Для задачи классификации простейшей функцией потерь является индикатор ошибки, вычисляемый по формуле I{y^≠y}\mathbb{I}\{\hat{y}\ne y\}I{y^​=y}, где функция индикатора I{условие}\mathbb{I}\{\text{условие}\}I{условие} возвращает 1, если условие выполнено, и 0 иначе. Забегая вперёд, скажем, что на практике для настройки моделей эту функцию применить нельзя, поскольку она не является дифференцируемой. Поэтому в классификации используются другие функции потерь, о которых будет рассказано далее.

Функция выигрыша

Функцию потерь не нужно путать с функцией выигрыша (score function) S(y^,y)S(\hat{y},y)S(y^​,y), которая также часто встречается в машинном обучении. Для более плохих прогнозов функция потерь должна принимать более высокие значения, а функция выигрыша - наоборот, более низкие.

Например, для классификации функцией выигрыша является индикатор верного угадывания класса I{y^=y}\mathbb{I}\{\hat{y}=y\}I{y^​=y}.

Теоретический и эмпирический риск​

Для настройки параметров модели w\mathbf{w}w традиционно желают минимизировать ожидаемые потери на новых объектах, поступающих из некоторого вероятностного распределения, называемые теоретическим риском:

E(x,y){L(fw(x),y)}=∫∫L(fw(x),y)p(x,y)dxdy→min⁡w\mathbb{E}_{(\mathbf{x},y)}\{\mathcal{L}(f_{\mathbf{w}}(\mathbf{x}),y)\}=\mathit{\int}\int\mathit{\mathcal{L}(f_{\mathbf{w}}(\mathbf{x}),y)p(\mathbf{x},y)d\mathbf{x}dy\to\min_{\mathbf{w}}}E(x,y)​{L(fw​(x),y)}=∫∫L(fw​(x),y)p(x,y)dxdy→wmin​

Практически эта величина невычислима из-за того, что мы не обладаем информацией о теоретическом распределении объектов p(x,y)p(\mathbf{x},y)p(x,y), а знаем лишь ограниченную обучающую выборку (x1,y1),(x2,y2),...(xN,yN){(\mathbf{x}_1,y_1),(\mathbf{x}_2,y_2),...(\mathbf{x}_N,y_N)}(x1​,y1​),(x2​,y2​),...(xN​,yN​). Поэтому на практике параметры w\mathbf{w}w находятся минимизацией эмпирического риска L(w)L(\mathbf{w})L(w), представляющего собой выборочную оценку теоретического риска по обучающей выборке:

L(w∣X,Y)=L(fw(x), y)‾=1N∑n=1NL(fw(xn), yn)→min⁡wL(\mathbf{w}|X,Y)=\overline{\mathcal{L}(f_{\mathbf{w}}(\mathbf{x}),\,y)}=\frac{1}{N}\sum_{n=1}^{N}\mathcal{L}(f_{\mathbf{w}}(\mathbf{x}_{n}),\,y_{n}) \to \min_\mathbf{w} L(w∣X,Y)=L(fw​(x),y)​=N1​n=1∑N​L(fw​(xn​),yn​)→wmin​

Оценка параметров w^\hat{\mathbf{w}}w^ определяется как минимизатор эмпирического риска:

w^=arg⁡min⁡wL(w∣X,Y),\widehat{\mathbf{w}}=\arg\min_{\mathbf{w}}L(\mathbf{w}|X,Y),w=argwmin​L(w∣X,Y),

где X∈RN×DX\in \mathbb{R}^{N\times D}X∈RN×D - матрица "объекты-признаки", также называемая матрицей признаков (feature matrix). Строки этой матрицы соответствуют DDD-мерным векторам признаков для каждого из NNN объектов обучающей выборки, а Y∈RNY\in \mathbb{R}^NY∈RN - вектор откликов, которые мы хотим научиться предсказывать по признакам.

Модель с настроенными параметрами также называют алгоритмом прогнозирования.

Параметры модели не стоит путать с гиперпараметрами (hyperparameters), которые не настраиваются по обучающей выборке, а задаются пользователем либо подбираются по отдельной выборке, называемой валидационной.
