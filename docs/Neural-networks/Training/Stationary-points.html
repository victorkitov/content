Классы точек стационарности

Рассмотрим точки стационарности w∗\mathbf{w}^*w∗, в которых градиент оптимизируемой функции становится в точности равным нулю:

∇L(w∗)=0\nabla L(\mathbf{w}^*) = 0∇L(w∗)=0

Мы минимизируем функцию потерь L(w)L(\mathbf{w})L(w) по весам модели w∈RK\mathbf{w}\in\mathbb{R}^Kw∈RK:

L(w)→min⁡wL(\mathbf{w})\to\min_\mathbf{w}L(w)→wmin​

Разложение Тейлора 2-го порядка [1] для L(w)L(\mathbf{w})L(w) имеет вид:

L(w^)≈L(w)+ΔwT∇L(w)+12ΔwT∇2L(w)Δw,L(\hat{\mathbf{w}})\approx L(\mathbf{w}) + \Delta \mathbf{w}^T \nabla L(\mathbf{w})+\frac{1}{2}\Delta \mathbf{w}^T \nabla^2 L(\mathbf{w}) \Delta \mathbf{w},L(w^)≈L(w)+ΔwT∇L(w)+21​ΔwT∇2L(w)Δw,

где

  • Δw=w^−w\Delta \mathbf{w} = \hat{\mathbf{w}}-\mathbf{w}Δw=w^−w;

  • ∇L(w)∈RK\nabla L(\mathbf{w})\in\mathbb{R}^K∇L(w)∈RK - градиент функции (вектор из частных производных по каждому весу);

  • ∇2L(w)∈RK×K\nabla^2 L(\mathbf{w})\in\mathbb{R}^{K\times K}∇2L(w)∈RK×K - матрица Гессе (Гессиан) из вторых производных {L(w^)∂wi∂wj}i,j\left\{\frac{L(\hat{\mathbf{w}})}{\partial w_i\partial w_j}\right\}_{i,j}{∂wi​∂wj​L(w^)​}i,j​.

Если раскладывать функцию потерь в стационарной точке w∗\mathbf{w}^*w∗, то разложение Тейлора [1] примет вид:

L(w^)≈L(w∗)+12ΔwT∇2L(w∗)Δw,(2)L(\hat{\mathbf{w}})\approx L(\mathbf{w}^*)+\frac{1}{2}\Delta \mathbf{w}^T \nabla^2 L(\mathbf{w}^*) \Delta \mathbf{w}, \tag{2}L(w^)≈L(w∗)+21​ΔwT∇2L(w∗)Δw,(2)

Гессиан, будучи симметричной матрицей, имеет ортонормированный базис из собственных векторов u1,...uK\mathbf{u}_1,...\mathbf{u}_Ku1​,...uK​ с собственными значениями λ1,...λK\lambda_1,...\lambda_Kλ1​,...λK​ [2]:

∇2L(w∗)ui=λiui,i=1,2,....K,\nabla^2 L(\mathbf{w}^*) \mathbf{u}_i = \lambda_i \mathbf{u}_i,\quad i=1,2,....K,∇2L(w∗)ui​=λi​ui​,i=1,2,....K, uiTuj={1, если i=j,0, если i≠j.\mathbf{u}_i^T \mathbf{u}_j = \begin{cases} 1, \text{ если } i=j, \\ 0, \text{ если } i\ne j. \end{cases}uiT​uj​={1, если i=j,0, если i=j.​

Разложим Δw=w^−w∗\Delta \mathbf{w} = \hat{\mathbf{w}}-\mathbf{w}^*Δw=w^−w∗ по базису из собственных векторов:

Δw=∑kαkuk\Delta \mathbf{w} = \sum_k \alpha_k \mathbf{u}_kΔw=k∑​αk​uk​

Подставив это разложение в (2), получим:

L(w^)−L(w∗)≈12(∑kαkuk)T∇2L(w∗)(∑kαkuk)=12(∑kαkuk)T(∑kαkλkuk)=12∑kλkαk2\begin{aligned} L(\hat{\mathbf{w}})-L(\mathbf{w}^*)&\approx\frac{1}{2}\left(\sum_k \alpha_k \mathbf{u}_k\right)^T \nabla^2 L(\mathbf{w}^*) \left(\sum_k \alpha_k \mathbf{u}_k\right) \\ &=\frac{1}{2}\left(\sum_k \alpha_k \mathbf{u}_k\right)^T \left(\sum_k \alpha_k \lambda_k \mathbf{u}_k\right) \\ &=\frac{1}{2}\sum_k \lambda_k \alpha_k^2 \end{aligned}L(w^)−L(w∗)​≈21​(k∑​αk​uk​)T∇2L(w∗)(k∑​αk​uk​)=21​(k∑​αk​uk​)T(k∑​αk​λk​uk​)=21​k∑​λk​αk2​​

Отсюда видно, что точка стационарности w∗\mathbf{w}^*w∗ может являться:

  • точкой минимума, когда все λi\lambda_iλi​ положительны (Гессиан - положительно определённая матрица);

  • точкой максимума, когда все λi\lambda_iλi​ отрицательны (Гессиан - отрицательно определённая матрица);

  • точкой перегиба, когда часть собственных значений положительна, а часть отрицательна.

Точки перегиба часто возникают при минимизации невыпуклых функций и затрудняют работу градиентных методов оптимизации, поскольку градиент в их окрестности становится малым, и обучение происходит медленно. Чтобы с этим бороться, нужно использовать методы оптимизации с инерцией - методы SGD+momentum или Adam.
