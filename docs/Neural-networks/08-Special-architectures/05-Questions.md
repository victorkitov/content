# Вопросы для самопроверки

- Какие возможности даёт добавление нейронов, вычисляющих радиальные базисные функции, к обычным нейронам, основанным на модели персептрона?
- Какие преимущества может дать использование гиперсети (hypernetwork) по сравнению с классической архитектурой?
- Как можно использовать автокодировщик для уменьшения размерности?
- Приведите возможные применения автокодировщика.
- Как автокодировщик может использоваться для обнаружения аномалий?
- Как автокодировщик можно применять в задаче предобучения глубоких сетей?
- Каково назначение контрастной функции потерь (contrastive loss)?
- Что произойдёт с эмбеддингами, если в контрастном обучении использовать только положительные пары?
- Приведите примеры «похожих» и «непохожие» объектов в контрастном обучении.
- В чём преимущества контрастного обучения по сравнению с классическим классификационным подходом?
